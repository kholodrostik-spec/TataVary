# Táta vaří — файли сайту

Повна поточна версія: чеська, англійська та польська мови; світла й темна теми; контурний логотип у жовтому колі в меню.

## Запуск
Відкрийте термінал у цій папці та запустіть:

```bash
python3 -m http.server 8000
```

Перейдіть до http://localhost:8000. Також можна використати Live Server у VS Code.
HTML відкриється подвійним кліком, але для завантаження content.json потрібен локальний сервер.

## Файли
- index.html — структура сторінки.
- style.css — стилі, адаптивність та дві теми.
- app.js — перемикачі, меню, галерея, форма та cookies.
- locales.js — усі тексти CS / EN / PL.
- content.json — меню, контакти, години роботи та галерея.
- assets/ — логотипи та favicon; залиште папку поруч з index.html.

## Контент
Невідомі дані залишені порожніми. Щоб додати справжню страву, внесіть у масив menu у content.json об’єкт такого формату, замінивши приклад реальними даними:

```json
{"category":"mains","name":{"cs":"Název","en":"Name","pl":"Nazwa"},"description":{"cs":"Popis","en":"Description","pl":"Opis"},"price":140,"allergens":[1,3,7],"image":"assets/food.webp"}
```

Категорії: mains, soups, desserts, drinks. Години hours — сім записів від понеділка до неділі: null або {"open":"11:00","close":"20:00"}.
Форма готує лист у поштовій програмі після додавання email; серверного надсилання немає. Юридичні тексти є чернетками до заповнення реквізитів.
